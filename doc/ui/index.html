设计说明与验收

视觉方向与假设

  • 暖橙 #F96C39 + 深可可文字，与 lib/core/theme/app_theme.dart 的品牌橙一致（J 图标为近似同色）；橙卡右上角一枚四角星芒呼应「AI 标识」，Tab「讲解」用声波弧呼应图标语义。
  • 提示词包 v0.1 写的是靛蓝 #4F46E5 纸感风，那是更早的备选、未经确认；本稿按更晚且反复精修过的图标色板统一。若要切回靛蓝，只需替换 3 个令牌（--brand / --brand-deep / --brand-soft），布局与组件不用动。
  • 首页定位为「操作型页面」：焦点是开始复习，数字与列表退居次级，不做营销式大标题和装饰。

业务红线（必须保留）

  • 主按钮脚注与演示流程都写明「先讲一遍，再评分」，不是一上来点「认识 / 不认识」。
  • 「讲解只追加、不覆盖」写在主卡脚注；录音为权威、转写只是副本写在演示流程第 2 步。
  • 数据对应 review_schedules.due_at、knowledge_points.mastery、learning_gaps.status=open；P1 统计表未定稿，概览数字按设计占位。

状态覆盖

  • 默认 / 逾期堆积 / 加载骨架 / 全部完成（空）/ 加载失败 五个整页状态。
  • 组件级：按钮 default / hover / pressed / focus / disabled，语言 chip 选中与未选，Tab 选中，逾期与错误提示条，成功结果卡。
  • 演示流程可走通：开始复习 → 回想 → 讲一遍 → 四档反馈 → 结果 → 回今日；关闭或点遮罩取消会清空状态。

出稿后逐条点检

  • 4 个 Tab 常驻且当前项高亮；语言切换在首页可见。
  • 复习入口通向同一个「讲一遍」流程；四档反馈标出下次间隔预览。
  • 逾期条目用文字 + 颜色双重表达，不只靠红色。
  • 图层是中文语义命名的可编辑矢量，不是整页位图。
