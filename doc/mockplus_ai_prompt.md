# Langly · 摹客3「小摹 AI」页面生成提示词包

> **状态：设计输入稿 v0.1（2026-11-09）** — 只写文档，未建库、未改 `lib/`、未加依赖、未在摹客里创建任何项目。
> 依据：`doc/sqlite.md` v0.2（多语言 / SM-2 / 支持语音）。本文件是**给摹客 AI 的需求输入**，不是 PRD 定稿。

## 一、怎么用它

1. 打开 <https://www.mockplus.cn/ai/>，登录摹客3，进入「小摹 AI」。
2. 设备选 **App / iPhone 15（390×844）**，风格选浅色（可再生成一套深色）。
3. 把下面「二、提示词正文」整段复制粘贴进去，一次性生成多页高保真设计稿。
4. 出稿后按「四、验收清单」逐页点检，再在摹客画布里微调。
5. 需要我读回设计稿时，把摹客设计稿链接给我 —— 见第五节。

> 若小摹 AI 一次生成页数有限，就按「先 P1 今日 + P6 复习 + P5 讲解」三页跑样例，
> 确认风格对了再补其余页面（与项目一贯的「先看效果 → 再规模化」节奏一致）。

## 二、提示词正文（复制这一段）

```
请为一个名为 Langly 的移动端语言学习 App，生成一套完整、可编辑的多页高保真设计稿（iPhone 15，390×844，浅色主题，并附一套深色主题）。

【产品定位】
记录语言知识点 → 用费曼学习法「讲一遍」讲清楚 → 按 SM-2 间隔重复温故 → 在复习中产生新理解。
它不是背单词卡 App，核心动作是「开口/打字把知识点讲给别人听」，并且每一轮讲解都只追加、不覆盖，用户可以对比第 1 轮和最近一轮看到自己理解变深。
支持多门目标语言并行学习；讲解支持语音（录音是权威载体，转写只是副本）。

【设计基调】
安静、克制、纸感的学习工具，参考 Notion / Linear 的信息密度和留白，不要游戏化、不要徽章堆砌、不要渐变和玻璃拟态。
主色靛蓝 #4F46E5，成功/掌握 #0F9D76，卡壳/待补 #E08A3C，危险 #DC4A4A。
背景 #F7F8FA，卡片 #FFFFFF，分隔线 #E8EAF0，主文字 #1A1D24，次文字 #6B7280。
圆角：卡片 16、按钮 12、小标签 8。间距基准 8 / 12 / 16 / 24。
字号：页面标题 22、区块标题 16、卡片标题 15、正文 14、辅助 12。中文字体用系统默认，数字与英文用等宽或系统无衬线。
组件请做成可复用组件：语言切换 chip、知识点卡片、掌握度 5 点、标签 chip、录音大按钮、四档反馈按钮、轮次时间线、空状态插画占位。

【底部导航（4 个 Tab，全局常驻）】
今日 / 知识点 / 讲解 / 我的

【页面 1｜今日（Tab 首页）】
- 顶部：问候语 + 当前目标语言切换（横向 chip：English / 日本語 / Español，可加号新增语言）。
- 概览卡：今日待复习条数、连续学习天数、本周已讲轮次，三个数字并排。
- 主行动按钮「开始复习（N）」，靛蓝实心、整宽。
- 「今日待复习」列表：每张卡片显示知识点标题、类型标签（单词/短语/语法/例句/发音/文化）、掌握度 5 点、到期时间（如「今天」「已逾期 2 天」，逾期用橙红）、关联标签 chip。点击进复习页。
- 次级入口「待补的卡壳点（N）」，橙色小标。
- 空状态：全部复习完的插画 + 「今天讲得不错，明天见」+「去记一个新知识点」按钮。

【页面 2｜知识点库（Tab）】
- 搜索框（占位「搜标题、笔记、讲过的话」）+ 筛选行：语言、标签、状态（draft/learning/explained/mastered）。
- 分组列表：按语言或按标签分组，卡片显示标题、释义摘要、类型、掌握度、最近讲解轮次与日期、是否有录音的小图标。
- 右下角悬浮「+」新建。
- 空状态：无知识点 / 筛选无结果两种。

【页面 3｜讲解记录（Tab）】
- 全局时间线：按日期倒序列出每一轮讲解，条目显示知识点标题、第 N 轮、输入方式图标（语音/文本/混合）、讲解语言、时长、是否卡壳。
- 顶部筛选：语言、输入方式、只看卡壳。
- 点击条目进知识点详情对应轮次。

【页面 4｜我的（Tab）】
- 学习概览：连续天数、累计讲解轮次、累计时长、各语言待复习量的横向条形。
- 「温故知新」时间线：复习中记下的新理解（insight）列表。
- 设置入口列表：每日复习上限、提醒时间、默认释义语言、默认讲解语言、SM-2 参数、录音存储与清理、深色模式、语言管理（停用某语言后不再进复习队列）。

【页面 5｜新建 / 编辑知识点（二级）】
- 字段：所属目标语言、标题（必填）、类型、原始笔记（多行，支持 Markdown 提示）、释义 + 释义语言、音标/读音、例句 + 例句译文、来源（教材页码/链接/时间戳）、标签（多选 chip）、难度 0–5、自评掌握度 0–5、星标。
- 底部「保存并开始讲一遍」主按钮 + 「仅保存」次按钮。
- 表单错误态与必填提示。

【页面 6｜知识点详情（二级）】
- 头部：标题、语言、类型、标签、掌握度、星标、编辑入口。
- 原始笔记区：笔记 / 释义 / 例句对照 / 来源。
- 「讲解历史」时间线：第 1 轮到最近一轮，每条显示轮次、日期、输入方式、讲解语言、时长、自评、是否用了行话；提供「对比首轮与最近一轮」并排视图（两栏文本 diff 感，体现理解深化）。
- 附件区：录音（可播放，显示转写状态：已转写 / 待转写 / 转写失败）、截图、链接。
- 「卡壳点」列表：未解决 / 已解决，点击进卡壳点清单。
- 底部双按钮：「再讲一遍」（主）、「加入复习」。

【页面 7｜费曼讲解页（核心，二级）】
- 顶部：知识点标题 + 「第 N 轮讲解」+ 讲解对象选择（讲给小孩 / 同伴 / 自己）。
- 输入方式切换：说话（语音）/ 打字 / 先说后补，切换时下方内容区随之变化。
- 语音态：中央大圆形录音按钮、实时计时、简单波形占位、暂停 / 完成 / 重录；下方是转写文本区，标注「转写仅为副本，以录音为准」，并显示转写状态（转写中 / 已完成 / 失败可重试）。
- 文本态：多行输入框，占位「假装对方完全不懂，用你自己的话讲」。
- 折叠区「简化再讲」：填一个类比/比喻，勾选「是否又用了行话」。
- 「卡壳了」区：一键记下讲不清的地方，生成待补卡壳点。
- 自评：这遍讲得顺不顺（0–5）。
- 底部「完成这一轮」；返回时二次确认（讲解只追加，不可覆盖）。

【页面 8｜复习页（核心，二级）】
- 步骤指示 1 → 2 → 3：回想 → 讲一遍 → 反馈。
- 第 1 步：只显示知识点标题与提示，答案/笔记默认折叠，按钮「想好了，开始讲」。
- 第 2 步：进入费曼讲解页（语音或文本），完成后回到本页。
- 第 3 步：四档反馈大按钮横排 —— 又忘了(Again) / 很吃力(Hard) / 想起来了(Good) / 太简单(Easy)，每档下标出对应的下次间隔预览（如「1 天后」「6 天后」「15 天后」「39 天后」）。
- 反馈后结果卡：本次 SM-2 参数变化（间隔、熟练度系数 EF）、下次复习日期。
- 文本区「这次新想到什么？」（温故知新，可留空）+ 保存并进入下一个。
- 顶部显示进度「3 / 12」，右上角退出复习。

【页面 9｜卡壳点清单（二级）】
- 分段：待补（open）/ 已解决（resolved）/ 暂缓（deferred）。
- 卡片：疑问原文、来自哪个知识点、第几轮讲解、登记日期；展开可填写「回查资料后的答案」并标记解决。
- 空状态：没有卡壳点的正向提示。

【关键交互流】
今日 →「开始复习」→ 复习页 →「讲一遍」→ 费曼讲解页 → 完成 → 回到复习页四档反馈 → 结果卡 → 下一个 / 回今日。
知识点库 → 卡片 → 知识点详情 →「再讲一遍」→ 费曼讲解页。
费曼讲解页里登记卡壳 → 卡壳点清单 → 回填答案 → 标记已解决。
知识点详情 →「对比首轮与最近一轮」→ 并排对比视图。

【状态与边界（请一并画出）】
空状态、加载骨架、录音权限被拒、转写失败但录音仍可播放、离线态、筛选无结果、表单校验错误、逾期复习条目。

【输出要求】
一次生成上述 9 个页面 + 底部导航 + 主要弹层；每个页面是可编辑的矢量图层与组件，不是整页位图；
图层与分组用中文语义命名（如「今日/待复习卡片」「讲解/录音按钮」）；颜色与文字样式做成可复用样式；
页面之间按上面的交互流建立可点击跳转，便于在摹客里预览。
```

## 三、页面与数据库的对应关系（自查用）

| 页面 | 主要数据表 | 页面必须体现的字段 |
| --- | --- | --- |
| 今日 | `review_schedules` + `knowledge_points` | `due_at`、`interval_days`、`mastery`、`language_id` |
| 知识点库 | `knowledge_points` + `tags` | `kind`、`status`、`gloss_lang`、软删 |
| 讲解记录 | `explanations` | `round_no`、`input_mode`、`lang_code`、`duration_sec`、`is_smooth` |
| 新建知识点 | `knowledge_points` + `languages` | 多语言三维度、标签多对多 |
| 知识点详情 | `explanations` + `attachments` | 只追加多轮、录音为准、`transcript_status` |
| 费曼讲解页 | `explanations` + `attachments` + `learning_gaps` | `audience`、`analogy`、`jargon_used`、`gap_notes` |
| 复习页 | `review_schedules` + `review_logs` | 四档 `result` → q 映射、EF 变化、`insight` |
| 卡壳点清单 | `learning_gaps` | `status` open → resolved |
| 我的 | `study_sessions`（P1）+ `settings`（P1） | 统计、语言开关、提醒 |

> 注意：P1 表（`insights` / `study_sessions` / `settings`）**尚未定稿**，页面 4 的统计部分按设计占位处理，别当成已确定的数据接口。

## 四、验收清单（出稿后逐页点检）

- [ ] 4 个底部 Tab 在每一页都常驻，当前项高亮。
- [ ] 9 个页面齐全，且「讲一遍」在首页、详情、复习三处入口都通向同一个费曼讲解页。
- [ ] 复习页是「先讲一遍 → 再四档反馈」，**不是**一上来就点「认识/不认识」。
- [ ] 讲解历史明确表达「只追加、不覆盖」，有首轮 vs 最近一轮的对比视图。
- [ ] 语音态标出「转写是副本、录音是权威」，且有转写失败仍可播放的状态。
- [ ] 多语言切换在首页与知识点库都可见，卡片能看出所属语言。
- [ ] 空状态、错误态、逾期态没有漏画。
- [ ] 深色主题一套，主色对比度可读。
- [ ] 图层是可编辑矢量，不是整页截图。

## 五、设计稿怎么回到项目里

摹客目前**没有 WorkBuddy 官方连接器**，我不能直接调用小摹 AI 生成页面；本文件因此采用「我在这里备好需求 → 你在摹客里一键生成」的路径。

社区有第三方 `@moke-mcp/cli`（Moke MCP），能力是**读取**已有摹客设计稿：图层树 / 结构化设计数据 / @2x 截图 / Design Token / 切图下载 / 设计规范文档，**不能创建或修改设计稿**。
若你希望我读回摹客稿并转成 Flutter 页面，需要：

1. 在 `app.mockplus.cn` 登录后，从浏览器开发者工具里取 Cookie（`MOKE_COOKIE`）。
2. 我把它作为自定义连接器写入 `~/.workbuddy/mcp.json`（现有 `pixso-remote`、`blender` 两项均为 disabled，会保留）。
3. 你在连接器管理页右上角「自定义连接器」里点信任启用。
4. 给我摹客设计稿链接，我就能读结构、取切图、抽 Design Token，再按 `lib/` 的 Flutter 结构落地页面。

> 配置需要你提供 Cookie，属于凭据，我不会主动去抓或写入日志。
