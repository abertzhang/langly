# VANTA-01 R2 · 1000cc 公升级概念参数表

> **设定值声明**：以下是本概念车的设计设定参数，用于校核造型比例、体量与工程合理性；**不是任何真实车型的参数，也不是实测数据**。参数表同时呈现在 `v2.html`。
>
> **版本提示（v3）**：动力、底盘、尺寸、性能参数对 `v3.html`（VANTA-01 R3）同样适用。v3 仅改动两处外观：大灯收成一条连续宽光带；排气由「短六边形斜切消音器 + 大块碳纤维隔热罩」改为「**双侧各 2 出、共 4 出小口径圆形短管，内嵌折面尾壳，细钛圈 + 极细青色内环**」。因此下表中「排气系统」一行以 v3 描述为准，其余不变。

排量核算：缸径 78.0 mm × 行程 52.2 mm × 四缸 = 997.7 cc ≈ **998 cc**，落在 1000cc 公升级（liter-class）区间。

## 造型调整项（v1 A → v2 R2）

- **大灯**：超薄光刃 → 加厚加宽的宽幅矩阵 LED 光幕（约 2 倍高度）+ 大幅加长的双竖向 DRL，构成 T 形前脸；前整流罩同步加宽加高。
- **车身**：油箱与折面侧壳加宽加厚、肩线抬高、轴距略拉长，视觉体量约 +15%。
- **动力**：纯电 + 外露电池模块 → 998cc 水冷直列四缸，缸盖散热片、水箱格栅、离合器盖、编织油管、四根排气头段外露。
- **排气**：无 → 双侧各 2 出共 4 出；六边形斜切短消音器上下阶梯错位，碳纤维罩，出口内嵌青色细光环，与折面尾壳一体化。
- **保留**：折面单体壳与贯穿脊线、每侧三道斜向鳍片、悬浮单座、短上翘尾 + 细红线尾灯、前后封闭碟轮 + 青色轮缘、哑光钛灰 / 电光青配色。

## 原创性边界（本版）

四出排气是公升级四缸街车的常见品类布局，本版在**实现形态**上拉开距离：六边形斜切截面（非圆管）、双侧上下阶梯错位（非四筒并列叠置）、与折面尾壳一体成型、出口内青色光环、碳纤维隔热罩 —— 与折面单体壳共用同一套设计语言。前脸仍为原创 T 形宽幅光幕，不做锐角双眼灯、不做叠层侧罩、无 Z 字标与厂商名、配色不含绿色。
