A · VANTA-01「棱面」你偏向的方向 · 主推

冷峻精密派。折纸式单体壳 + 一条贯穿式光刃，靠切面和明暗塑形，不靠装饰件。适合想要「近未来、量产感、冷科技」的方向。

前脸　贯穿式超薄光刃 + 两端竖向 DRL，无传统灯罩
上部　折面单体壳，一条脊线从车头贯到车尾
侧面　每侧三道斜向导流鳍片，取代排气的视觉重量
中段　三角铝车架镂空，电池模块外露
行走　前后封闭碟轮 + 细青色发光轮缘环
尾部　悬浮单座、短上翘尾、细红线尾灯

B · AURA-02「环流」对照方案

有机流体派。一条连续光环从车头绕到座下，壳体悬浮留空，靠曲面与光带流动感塑形。更概念、更柔和，也更像「展示用车」。

前脸　大圆形光环 DRL + 中央单眼投影灯
上部　翼形壳体悬浮，与座垫间留明显空气层
侧面　一条熔岩橙光带沿腰线从前环流到车尾
中段　连续曲面，中央脊梁连接前后
行走　单摇臂 + 轮毂电机实心后盘
尾部　短圆尾，内凹 U 形尾灯

原创性边界：参考了什么、改掉了什么

本表仅适用于本页 v1 两案。以 Z1000 所属的街车（naked / streetfighter）品类为比例参照，不复用其任何识别性设计元素；v1 两款均为纯电动力总成，从根上避开燃油街车的经典布局。A 的后续调整版已改为 1000cc 燃油四缸 + 双侧四出，边界说明见 v2 页。

维度处理方式
只借鉴宽平车把、略前倾的骑行三角、裸露机械感、短尾、前后轮比例 —— 这些是街车品类的通用比例，不构成特定车型特征。
明确改掉① 纯电驱动，无四缸缸体、无排气管（尤其不做四出排气）—— v1 设定，v2 已按需求改为四缸四出 ② 前脸全新：贯穿光刃 / 圆形光环，不用锐角双眼灯 ③ 不做叠层侧罩与散热片造型 ④ 无 Z 字标、无厂商名、无任何商标 ⑤ 两款配色均不含绿色。
原创设计点折纸式单体壳 / 悬浮环流壳体、发光碟式轮毂、光带式尾灯、外露电池模块、单摇臂轮毂电机、以导流鳍片替代排气视觉重心。
法律边界虚构概念代号 VANTA-01 / AURA-02，草图中的手写注释为无意义笔迹；未使用任何实车照片、车标、专利造型或品牌绿。
